# 裁判文书研习平台：产品体验深度盘点（非技术）

日期：2026-09-24｜性质：讨论稿，不是整改方案；方向确定后再形成方案。

## 〇、我是怎么看的

- 在本地完整构建网站，以“第一次来的法学本科生”身份，从首页一路走到课程、案例、研习、实验、档案、帮助、登录和交流区。
- 看了电脑宽屏（1440）和手机（390）两种尺寸，浅色和深色两种模式。截图保存在 `output/ux/`（不进入 Git）。
- 交流专区、登录、工作区需要后台服务，本地预览时显示“学习服务暂不可用”。线上如果尚未接好数据库，学生看到的也会是这个样子。
- 课程视频来自外部地址，本地环境无法播放，所以只评价了视频页的版式，没评价视频本身。
- 本文只谈布局、功能、使用链路、文案和外观，不谈代码。

## 一、总体判断

**内容是扎实的，态度是诚实的，但网站在同时对三种人说话，所以显得“摇摆”。**

1. **学生**：欢迎信、使用指南、研习工作台是写给学生的，语气温暖，引导具体。
2. **评审专家／来访者**：首页的“一核·两翼·三阶·六能·双环”、“四个维度的教学改革成果”、课程材料里的“课堂观察表、互评问卷、职责分工表”，是写给看教改成果的人的。
3. **开发者自己**：“建议预留45—60分钟（教学参考，非实测）”、“进度来自本浏览器保存的学习产出”、“对照结果不等于法律适用评价”这类句子，是为了严谨而写的免责说明，却直接出现在学生眼前。

三种声音交替出现，学生会感到：这是一个给我用的学习工具，还是一个给别人看的成果展板？这是本次盘点最核心的问题，后面大部分问题都是它的具体表现。

第二个整体问题是**学习主线被稀释**。同一件事常常有两到三个入口、两到三个名字，首页和各栏目之间重复介绍自己，学生要花力气分辨“我现在该点哪里”。

## 二、谁在用这个网站

| 使用者 | 他们来做什么 | 网站现在给他们的 |
|---|---|---|
| 刚接触法理学的学生 | 知道从哪里开始、读懂一个案例、写出第一段有依据的分析 | 欢迎信和指南很好，但首页第一屏是项目口号和统计数字 |
| 有基础的学生 | 快速找到某类案例、做实验、积累自己的产出 | 案例检索做得不错；实验入口清楚；但“我的产出”分散在两处 |
| 任课教师 | 布置任务、看提交、写点评 | 教师工作台（需登录）；公开页面里混入大量“教学设计材料” |
| 实务导师 | 参与讨论、点评 | 交流区的导师邀请；公开页没有导师的位置感 |
| 评审专家／来访者 | 了解这个教改项目做了什么、成效如何 | 首页的“教学成果”板块、课程“档案”式呈现 |

**需要你定的第一件事：谁是首要使用者？** 我的建议是学生优先，把“给评审看的内容”集中到一个独立的“关于本项目”页面，不再占据学生的学习动线。

## 三、使用链路走查

以“一个第一次来的同学，想读懂一个案例并完成一次练习”为线索，逐步记录体验。

### 1. 第一次打开

- **做得好**：欢迎信文字真诚，有文学性（“愿你保有好奇，也给自己留出慢慢理解、重新审视的时间”），给出“查看使用指南／开始法理学探索”两个清楚的去向。
- **问题**：关掉欢迎信后，首页从上到下是——
  1. 一张“从这里，开始法理学探索”的横幅；
  2. 一张写着“一核·两翼·三阶·六能·双环”的深色大横幅，重复网站名称；
  3. “继续研习：接着上次的案例继续”；
  4. 课程认知／案例研习／仿真实验三张卡片；
  5. 八期课程视频成果；
  6. “快速开始”三个入口，内容与第 4 项基本重复；
  7. 精选案例；
  8. 四个维度的教学改革成果。

  首页讲了三遍“课程—案例—实验”，讲了三遍“8期课程”。
- **问题**：新同学从没学过，却看到“**接着上次的案例继续**”，还带着“0/3”的进度。这是一句不真实的话。
- **问题**：“210+ 典型案例”。实际正好 210 篇，“+”是宣传口吻，与网站其他地方的严谨态度不一致。

### 2. 找到课程

- 左侧导航叫“**课程认知**”，点进去页面叫“**八期课程档案**”，小标题叫“**课程体系**”，返回按钮叫“← 课程体系”。一个栏目三个名字。
- 课程页上半部分是“第一期至第四期／第五期至第八期”的切换卡片，下半部分又把八期全部列一遍（视频卡片），描述文字完全相同。
- 八个视频封面是同一种深蓝底加大号数字，没有画面，看不出每期的差别。
- 进入某一期（如第三期）后，信息很丰富：真实的理论导师、实务导师，好的问题意识（“真正讨论的不是商事仲裁好不好，而是……”）。**这是网站最有价值的内容之一。**
- **问题**：期页的“材料阅读提示”在用第三人称谈学生，如“任务单并不要求学生背仲裁法，而是要求他们判断……”。这是教师备课口吻，不是对学生说话。
- **问题**：每期的课程材料目录是“教学设计类／课堂实施类／协同反思类／学习成果类”，包括职责分工表、课堂观察表、互评问卷、能力指标体系。对学生来说，其中一半是“老师用的表格”。

### 3. 读一个案例

- **做得好**：案例检索的筛选很实用，“下一步筛选”会根据当前结果推荐下一个条件，这是很聪明的设计；结果卡片有案由、法院层级、裁判结果、日期、摘要和法条，信息完整。
- **问题**：案例详情页最显眼的“导读判断”三格是模板句，几乎不提供信息——
  - “这案子在讲什么：买卖合同纠纷。本案围绕‘买卖合同纠纷’展开，进入全文前可先据此判断案件的核心争议。”
  - “为什么值得读：撤销原审裁判。先看这句裁判结论如何回应上面的争议……”
  
  真正有价值的内容（“本案争议焦点主要有三点：其一，合同第二十一条‘按第2种方式处理’与条内‘(2)’序号并存时，应如何解释……”）在页面更下方的“案例摘要”里。**最好的内容被放在了最不显眼的位置。**
- **问题**：自然人姓名处理不一致。有的案例写“李某甲、罗某”，有的写全名（如“周蓉蓉”“张保林”“王立艳”“赵海”）。对一个讲法理、第六期还专门讨论“人脸识别中的同意边界”的平台，这一点值得统一，建议对自然人一律匿名化。

### 4. 做研习（三步研习工作台）

- **做得好**：左边读材料、右边写作的分屏形式是对的；分三步（事实—争点—分析）的结构清楚；写完才开放法院结论，避免先看答案，这个理念很好。
- **关键问题：答案就摆在旁边。** 第一步的写作任务是“请提取关键事实：当事人是谁、发生了什么……”，而左边的“整理材料”栏里已经写好了“事实梳理”和“争议焦点”两段。学生只要照抄，就能“完成”前两步。结论藏起来了，但事实和争点没有藏。
- **问题**：用“写满 50 字”作为解锁下一步的条件。字数只能衡量“写了多少”，不能衡量“想了没有”，学生容易凑字。
- **问题**：进入工作台后，左侧导航突然缩成只有图标的窄条，图标又几乎都一样（多个“书本”图标），学生会失去方向。

### 5. 做实验

- **做得好**：六个实验各有明确的训练对象（推理、论证、检索、解释、衡量、批注）；实验内部“大前提—涵摄—小前提”的拼装式设计直观，素材点选降低了门槛。
- **问题**：实验中心和每个实验顶部都有“微循环五步：案例进入（文本形态）、法理锚点（纲的角色）、动手产出（操作形态）、对照反思（人格形态）、存档铸能（证据形态）”。“纲的角色”“人格形态”“存档铸能”对学生来说几乎无法理解。这是项目申报书的语言。
- **问题**：“以理驭案·以案证理·以练铸能”这类口号句，在学生页面上是装饰，不是引导。
- **问题**：选择案例的卡片上，特征标签几乎都是“三段论结构清晰”“争点明确”，区分度很低，帮不了学生选择。

### 6. 保存与回看

- **问题：学生的学习成果有两个家。** “研习档案”存在当前浏览器里，换设备要导出 JSON；登录后的“我的任务”存在云端。使用指南里专门有一段“先分清两种保存方式”，说明设计者自己也意识到这很难懂。对文科学生来说，“JSON 备份”是一个陌生且有压力的概念。
- 研习档案的空状态文案（“看见每一次判断如何累积”）很好，但页面下半部分立刻是“导出或清理”“导入备份（最多 2MB 的 JSON 文件）”，技术操作的比重过高。

### 7. 交流与资料

- 左侧“交流与资料”分组里有三项：交流专区、资料专区、场景研习。
  - **场景研习**其实是一种实验（和“仿真实验”同类），放在“交流与资料”下不合逻辑。
  - **资料专区**目前是空的（“资料正在整理”），却占据主导航的一个位置。空房间放在主导航里，会降低整个网站的完成感。
  - **交流专区**需要登录；未登录或服务未就绪时，学生只能看到“学习服务暂不可用”。
- 登录页上直接写着“初始密码为学号后六位”。这对学生是方便，但等于公开告诉所有人如何登录别人的账号（技术盘点 R02 已记录）。

### 8. 帮助与反馈

- **做得好**：帮助中心、图文指南、意见反馈三件套完整；指南的标题“从一个案例，开始理解法律”和导语“你不需要先记住所有概念”是全站写得最好的学生文案之一。
- 这里的语气，应该成为全站的语气基准。

## 四、信息架构与命名

### 同一件事的不同叫法

| 实际指的东西 | 网站上出现的名字 |
|---|---|
| 八期课程 | 课程认知、课程体系、八期课程档案、课程档案、全部课程 |
| 学生自己的学习记录 | 研习档案、本地记录、我的研习档案、实验存档、我的任务、工作区 |
| 案例部分 | 案例研习、案例检索、案例库、案例检索与原文入口 |
| 三步写作 | 三步研习、研习工作台、案例研习、推理构建与评价 |

“档案”一词同时指“课程档案”和“学生的研习档案”，最容易混淆。

**建议**：先统一一张“名词表”，每个概念只保留一个名字，导航、标题、按钮一律使用它。

### 导航结构

- 当前主导航：首页、课程认知、案例研习、仿真实验、研习档案、帮助与反馈；另一组：交流专区、资料专区、场景研习；底部还有反馈链接、两个数字统计（研习案例 0／实验存档 0）、“开放浏览·案例研习平台”和“账号登录”。左侧栏底部信息过于拥挤。
- 图标重复：课程认知、帮助与反馈、交流专区、资料专区都用“书本”图标；仿真实验和场景研习都用“烧瓶”图标。图标失去了帮助识别的作用。
- `/resources/`（资源）页面的内容与课程页完全相同，是一个重复入口。

**一个可供讨论的简化方案**：

- 学习：首页／课程／案例／实验（含场景研习）
- 我的：我的学习（合并本地与账号）
- 交流：交流专区（资料专区有内容后再出现）
- 底部：帮助、账号

## 五、文案与语气

| 语气 | 典型句子 | 适合的地方 |
|---|---|---|
| 温暖、邀请式 | “你不需要先记住所有概念。带着一个问题，读一份文书、写下理由……” | 全站学生页面的基准 |
| 汇报、申报式 | “一核·两翼·三阶·六能·双环”“四个维度的教学改革成果”“存档铸能” | 只放在“关于本项目” |
| 备课、第三人称 | “任务单并不要求学生背仲裁法，而是要求他们判断……” | 教师工作台或教师版材料 |
| 免责、工程式 | “教学参考，非实测”“进度来自本浏览器保存的学习产出” | 缩减为一处简短说明，或放进帮助页 |
| 模板、空转 | “本案围绕‘买卖合同纠纷’展开，进入全文前可先据此判断案件的核心争议。” | 应替换为真实的争议问题 |

另外两点：

- 诚实标注（如场景研习的“教学假设情境·尚未经教师审阅”）是好的，应该保留，但可以用更友好的方式表达，比如一个小徽标加一句说明。
- 课程标题和问题意识写得很有水平（如“从‘沉睡的权利’到正当救济的司法考量”），说明内容团队的文字能力很强，问题主要是**不同场合的语气没有分开**。

## 六、视觉与美学

### 现状

- **配色**：深海军蓝（侧栏、横幅、按钮）＋橙色点缀（选中状态、编号、链接）＋浅灰底白卡片。稳重、专业，但偏“企业后台／数据看板”，缺少人文学科的气质。
- **字体**：标题黑体加粗，数字用衬线体（“210+”“8期”），编号用等宽字体（“01”“02”），小标题左侧加竖线的“眉题”遍布全站。三种字体气质混用，略显杂。
- **版式**：卡片套卡片——大白卡里分格，格里再放小卡片或标签。每个板块都是“竖线眉题＋大标题＋灰色说明＋内容”的同一模板，页面节奏单一，信息层级不够分明。
- **图像**：全站几乎没有图像。视频封面是同一个深蓝占位图，课程没有配图，案例没有视觉线索。法学文本本身抽象，完全没有图像会让页面显得冷。
- **标签**：大量灰边小标签（案由、层级、法条、特征），信息多但视觉分量都一样，重点不突出。
- **手机端**：
  - 首页第一屏被两张介绍卡占满；
  - 案例检索页要滑过标题、统计、搜索、“下一步筛选”后才看到第一个案例；
  - 研习工作台在手机上变成“先读很长的材料，再往下写”，读写无法对照。
- **深色模式**：案例详情页的“新窗口打开 PDF”按钮在深色模式下是浅灰底配白字，几乎看不清。

### 可以讨论的方向

你可以想一想，这个网站应该让人联想到什么：

- **A. 书卷／学术期刊**：米白纸色底、宋体（衬线）正文、克制的墨色和一个印章红或法院绛红作点缀，大量留白，像在读一本好的法学读物。与“研读裁判文书”的气质最吻合。
- **B. 现代学习工具**：保持现在的深蓝体系，但减少卡片与边框，加大留白，统一字体，只保留一种强调色。改动较小。
- **C. 两者结合**：阅读区域（案例、课程正文、研习材料）用书卷风，操作区域（筛选、实验、档案）用工具风。

我个人倾向 **A 或 C**：研读文书是一种沉下心来的阅读活动，版面应该帮助人慢下来，而不是像看数据报表。

## 七、应当保留和放大的优点

1. 欢迎信与使用指南的温度和文字质量。
2. 每期课程真实的问题意识与双导师信息。
3. 案例检索的“下一步筛选”推荐。
4. 左读右写的研习形式，以及“写完再看法院结论”的理念。
5. 实验中的素材点选、拼装式推理。
6. 不把“浏览”算作“完成”、诚实标注未审阅内容的严谨态度。
7. 明暗模式、手机端、键盘操作都有基本适配。

## 八、需要和你讨论的关键问题

1. **首要使用者是谁？** 学生优先，还是兼顾评审展示？是否把教改成果集中到一个“关于本项目”页面？
2. **学习主线从哪里开始？** 以“八期课程”为主线（按期推进），还是以“案例”为主线（自由探索）？首页应该只突出一条。
3. **“我的学习”能否合并成一处？** 学生不需要理解“本地”和“云端”，只需要知道“我写的东西在这里”。
4. **研习是否应该“先写后看”？** 把事实梳理、争议焦点也放到学生写完之后再对照展示，并用“对照要点自查”替代“写满 50 字”。
5. **给学生看的课程材料要不要分版本？** 学生版只保留导学、任务单、阅读材料；观察表、互评问卷、职责分工放到教师侧。
6. **网站的视觉气质选 A、B 还是 C？**
7. **场景研习、资料专区、交流专区放在哪里？** 资料专区在有内容前是否先不出现在主导航？
8. **案例中自然人姓名是否统一匿名化？**

## 九、可以先做的小改动（不依赖上面的大决定）
