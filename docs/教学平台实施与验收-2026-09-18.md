# 教学后台、场景研习与交流区：实施与验收记录

日期：2026-09-18，更新至2026-09-19。对应 `docs/superpowers/specs/2026-09-14-teaching-console-simulation-community-spec.md`。本地实现与本轮验收已通过，尚未推送或部署；线上原站不代表以下功能已经上线。

## 已实现的主要路径

- `/login/`：真实服务端会话、账号停用与凭据重置后的撤销、CSRF 与登录限流；无公开角色切换。
- `/workspace/`：授权任务、账号云草稿、提交快照、教师意见、修订再提交、本人选择导入历史记录。草稿保存与提交分开。
- `/teacher/`：范围内统计、小组与任务管理、不可变任务版本、提交查看、逐项反馈、筛选导出；导师按任务授权。
- `/admin/`：账号、角色、小组关系、交流治理、脚本发布状态、审计；最后一个有效管理员受数据库保护。
- `/community/`：提问、回答、两层追问、投票、举报、锁定与隐藏、通知、小组内部讨论及导师邀请。删除问题保留占位与已有回答，并阻止新增回答；隐藏内容仍不可由普通用户查看。
- `/experiments/scenes/`：校园人脸识别门禁听证的二维／2.5D场景、两个角色、七个节点、材料与异议、标准模式、版本化课程提交。脚本为原创教学假设情境，尚未经教师审阅。

本轮补充修复：恢复本地草稿继续携带其原版本，避免绕过并发检查；冲突时展示云端稿，允许导出当前稿或主动合并；等待本地恢复选择期间禁用编辑；云保存成功不因本地缓存清理失败而误报；退出后即使缓存清理失败也清除界面身份；同一任务并发开始及同一重启请求返回同一实例；同一资源刷新保留编辑区与成功提示。健康检查核对服务使用的表与关键字段，不仅检查用户表存在。

## 本地运行

建议使用 Node 22；实际依赖由 package-lock.json 锁定。

```bash
npm ci
npm run db:migrate:local
npm run build
npm run preview:full
```

完整服务地址 `http://127.0.0.1:3015/`。`npm run dev:full` 合并迁移、构建和启动。`npm start` 只支持静态页面，不能拿它核验账号及 API。

`setup:local` 生成被 Git 忽略的 `wrangler.jsonc`，项目名为本地专用名称，数据库 UUID 为占位值；不得作为生产配置上传。`.wrangler/` 是本地数据，也不提交。

初始化本地维护者：通过环境变量 `FAXUE_INIT_LOGIN`、`FAXUE_INIT_NAME`、`FAXUE_INIT_PASSWORD` 提供账号、显示名与至少12字符密码，再执行 `npm run init:maintainer:local`。脚本只写本地库，密码不作为命令行参数；执行后清除该密码环境变量。不要把真实凭据、学生清单或本地测试库放进 Git。正式初始化仍待生产环境和凭据交付方式确定。

## 验证入口与证据

```bash
npm run check

FAXUE_BROWSER_TESTS=1 PLAYWRIGHT_CHANNEL=chrome npm run test:server
# 一次运行上述完整链
PLAYWRIGHT_CHANNEL=chrome npm run check:full
```

服务测试实际执行 Pages 入口、workerd 与隔离 D1，并应用全部迁移；不是模拟数据库或前端假身份。浏览器使用隔离测试账号，销毁测试库，不触碰线上数据。未设置 `FAXUE_BROWSER_TESTS=1` 时会跳过服务测试中的真实浏览器部分，不能据此宣称全部验收通过。

## 部署、备份与回退

当前迁移为0001—0009。预览与正式库必须分开，正式库不得灌入测试账号、帖子或测试会话。本地占位配置不能部署。

取得真实数据库与配置后，在每次迁移前使用 Wrangler D1 export 对目标远端库导出至受控备份位置（配置文件和数据库名必须替换为已核对值）。备份包含个人记录与凭据哈希，不入 Git，不公开下载。先在独立恢复库导入并核对用户角色、小组成员、任务版本、提交、反馈、帖子关系和外键，再作生产迁移。隔离恢复流程先在空库恢复表结构与数据，再恢复并逐一比对触发器，以免“禁止归档后写入”的业务约束误拦历史数据回灌；不对生产库停用触发器。当前自动恢复测试仅证明隔离数据的导出回灌行为，不能代替这一步。

应用回退须保留新增数据库数据，先确认旧应用兼容现有表结构；不要用旧备份直接覆盖上线后的新提交。必要时暂停写入，保留原库，再恢复到新库验证。正式备份保留期限、存放位置与恢复联系人待实际托管设置确定后记录，不能编造。
